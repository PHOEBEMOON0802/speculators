D-MTP2 训练逻辑与流程

speculators 库 · 冻结 MTP 首词 + DFlash2 并行续写 + 候选重排 的投机解码草稿模型 · 以 Qwen3.6-35B-A3B 为例

1一句话概览

D-MTP2 = D-MTP 的首词路径 + DFlash2 的主干。 每个草稿块(block)的第一个草稿词 T1 由 verifier 自带的、冻结的原生 MTP 模块提出(首词最难,交给最强的预测器); 块内其余位置由 DFlash2 主干一次并行前向补全(带局部动态卷积), 并由一个前驱词条件的候选重排器(candidate selector)对每个位置的 top-k 候选重新打分。 两个机制互补:D-MTP 解决"第一个词就错"的问题,DFlash2 改善块内位置越靠后越不准的衰减问题。

训练中 verifier、它的 MTP 块、embedding、LM head 全部冻结; 真正更新的只有 DFlash2 草稿层(含动态卷积)、candidate selector、以及一个很小的 fusion 融合模块。

2模型组成:谁冻结、谁训练

组件来源状态作用
mtp_layers + mtp_rotary_emb verifier 原生 mtp.* 权重(经 MTPConverter 抽取) 冻结 为每个 anchor 提出 T1 的 hidden(训练时 teacher forcing,只取 hidden)
embed_tokens / lm_head / verifier_lm_head / verifier_norm verifier 共享(保存在 checkpoint 中) 冻结 词嵌入、草稿 logits 投影、蒸馏目标(verifier logits)的构造
layers.*(Qwen3DFlash2DecoderLayer ×N) DFlash2 warm-start 迁移 / 随机初始化 训练 草稿主干;每层在 attention 和 MLP 前后包一对 GroupedDynamicCausalConv 局部动态卷积
fc / hidden_norm / norm DFlash2 warm-start 迁移 训练 fc 把 verifier 的多层 aux hidden states 拼接后压回草稿 hidden 维度,作为每层 cross-attention 的 target

fusion(MTPTokenFusion) 全新模块(warm-start 时可选 identity 初始化) 训练 把 T1 的词嵌入和预测它的 MTP hidden 融合成 slot 1 的输入:

3草稿块布局

训练把序列中采样出的每个 anchor 位置展开成一个长度为 B(block_size,如 8)的块:

slot 0 — Aanchor:已提交词
输入,无损失
slot 1 — T1MTP 首词(训练用真值)
输入,无损失
slot 2 — MASK草稿位 · 有损失
slot 3 — MASK草稿位 · 有损失
……
slot B−1 — MASK草稿位 · 有损失

与普通 DFlash 的 [A, MASK×(B−1)] 不同,D-MTP2 是双 anchor 布局 [A, T1, MASK×(B−2)]: slot 0 和 slot 1 都是"已知输入",损失只覆盖 slot 2..B−1 的 B−2 个续写位。 推理时一个块产出 B−1 个草稿词(T1 + B−2 个续写)再加 verifier 的 bonus token。

4端到端训练流程(在线模式)

Step 0 · Warm-start(可选但强烈推荐)
python -m speculators.convert.dmtp.warmstart <dflash2_ckpt> --verifier <verifier> --output <dir> --identity-fusion-init

5单个训练步的前向细节

输入(来自 vLLM):packed 序列的 input_ids、aux 层拼接 hidden hidden_states、最后一层 hidden verifier_last_hidden_states、loss_mask、document_ids。

① Anchor 采样与注意力掩码

从 loss_mask 有效、且不跨文档边界的位置中采样至多 max_anchors 个 anchor。 每个 anchor 展开成一个 B 长的块,拼在原序列之后。块内使用双向(非因果)滑窗注意力 (sliding_window_non_causal=True),块对上下文则做跨文档隔离的因果 cross-attention。

② 构造块输入(D-MTP2 的关键差异点)

slot 0 填 anchor 词嵌入,slot 2+ 填 mask_token_id 的嵌入;slot 1 走 fusion 路径:

冻结 MTP 前向(_compute_mtp_hidden,no_grad):对整条 packed 序列做一次因果 MTP pass—— 输出位置 t 由 verifier hidden ht 和词 xt+1 的嵌入算出,预测 xt+2。 anchor p 的 T1 就是 xp+1,所以预测它的 hidden 位于索引 p−1,按此取出每个 anchor 的 h_MTP。

融合:slot 1 先填入真值 T1(teacher forcing,即 anchor 的下一个词),它的嵌入被替换为

ẽ_T1 = W_f · [ RMSNorm_e(e_T1) ; RMSNorm_m(h_MTP) ]   (2d → d,无 bias)

③ DFlash2 主干前向

verifier 的 aux hidden 先经 fc 压缩成 target hidden。每个草稿层: 输入 LayerNorm → attention_conv.prepare(块内因果动态卷积)→ 对 target hidden 做 cross-attention → attention_conv.finish → 残差;MLP 一侧同理包在 mlp_conv 里。 卷积核 = 静态 base kernel + 由当前 hidden 投影出的逐词 delta,分组共享(conv_group_size), 初始化为恒等变换(warm-start 迁移后保留训练值)。最后 norm + lm_head 得到每个块位置的 unary logits。

④ 蒸馏目标

目标不是 one-hot 真值,而是 verifier 的完整 logits 分布: targets = verifier_lm_head(verifier_norm(h_last)),按"块内位置 i 预测序列位置 anchor+i 的下一个词"对齐(整体 roll 1)。 默认损失为 KL 散度(可配 --loss-fn)。

⑤ Selector 打分

对每个草稿位取 unary logits 的 top-k(selector_top_k,如 16)候选;若真值不在候选中,按 selector_miss_policy=replace 把最后一名替换为真值(仅训练时)。selector 对候选加转移分:

score(c) = unary_logit(c) + ⟨ P[prev] ⊙ W_h·h , S[c] ⟩   (P/S 为词表级 codebook,秩 = selector_rank)

其中 prev 是该位置的前驱词(块内左移一位,teacher forcing)。

6损失函数

L = L_unary + α · L_selector   (α = selector_loss_alpha,默认 1.0;slot 0/1 损失恒为 0)
项内容
L_unary 草稿 logits 对 verifier logits 的 KL 蒸馏,逐位置加权。权重两种模式:
· fixed-exp-decay(默认):slot 1 起权重 exp(−(pos−1)/γ),γ=dflash_decay_gamma(默认 4);
· dpace(D-PACE):用每个位置的即时置信度 q=exp(−CE) 做块内累乘,按"前面全部被接受的概率"加权 (dpace_alpha 平滑),让损失聚焦在实际可达的位置上。
L_selector top-k 候选上的交叉熵(目标 = 真值在候选中的位置),同样做位置衰减加权; strict 模式下真值不在候选中的位置不计损失,replace 模式下替换后全部计入。

7训练监控指标

指标含义
eal头号指标:realized selector-path 期望接受长度——以 T1 给定为条件,selector 实际选中的词与真值的逐位匹配连续长度(从 slot 2 起)+ bonus。
position_i_acc块内第 i 位的 unary argmax 准确率,直接反映位置衰减曲线。
unary_candidate_recall_at_k真值落在 unary top-k 候选内的比例(selector 的天花板)。
teacher_forced_selector_acc候选包含真值时,selector 选对的比例。
unary_top_k_oracle_accepted_length假设 selector 完美时的接受长度上限(诊断瓶颈在 unary 还是 selector)。
unary_loss / selector_loss两个损失项分量。

9推理时的对应语义

部署后每个解码步:verifier 正常前向并产出 bonus token 作为新 anchor → 冻结 MTP 块用 verifier hidden 提出 T1 → DFlash2 主干以 [A, T1, MASK×(B−2)] 一次并行前向补全 → 每个续写位取 unary top-k、 selector 以左侧已选词为前驱重排、取最高分 → B−1 个草稿词交 verifier 一次验证,接受最长匹配前缀。 训练中的 eal 直接估计这条路径的期望接受长度。
